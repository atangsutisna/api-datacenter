## HOW TO RUN RASA AI CHATBOT
pip install rasa
rasa init
perintah ini akan menghasilkan folder dan file berikut:
** folder actions

** folder data
- nlu.yml
Definisikan semua intens di sini

- rules.yml
Response yang 

- stories.yml
Interaksi antara bot dan user

** folder tests
** file config.yml
** file credential.yml
** file domain.yml
** file endpoints.yml/

RUN RASA
------------------------------------------------
rasa shell
------------------------------------------------
dengan perintah tersebut akan masuk ke terminal rasa

--------------------------------------------------
rasa train
--------------------------------------------------
perintah "train" diketik setelah melakukan perubahan terhadap folder data atau folder-folder inti rasa (doamin.yml, nlu.yml, stories.yml dll)

---------------------------------------------------
rasa run --enable-api --cors "*"

## agar tidak berhenti prosessnya ketika terminal ditutup
nohup rasa run --enable-api --cors "*" > rasa.log 2>&1 &
nohup rasa run actions > actions.log 2>&1 &
## cara menghentikannya
ps aux | grep rasa
## akan muncul seperti ini
youruser  12345  0.0  ... rasa run --enable-api --cors "*"

## jika belum mati, gunakan ini
kill -9 12345
